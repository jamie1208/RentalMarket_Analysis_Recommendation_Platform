# RentPersona：租屋族群分析與推薦平台

RentPersona 是一個以 **租屋族群分群（Clustering）** 為核心的租屋推薦平台。  
透過資料分析將租屋市場劃分為不同族群，協助使用者快速找到符合自身需求的房源，並降低找房時的理解與決策成本。

---

## 📌 專案動機（Project Motivation）

現有租屋平台大多以「租金、坪數、地區」作為篩選條件，但對於使用者而言，往往仍難以判斷哪一類房源真正適合自己。

本專案嘗試從「**你屬於哪一種租屋族？**」的角度出發，  
先將租屋市場進行分群，再根據族群特性提供推薦與市場分析，  
讓找房過程更直覺、更有效率。

---

## 🧠 專案特色（Features）

- 以 **租屋族群（Persona）** 為導向的找房流程
- 使用 **K-means** 進行租屋市場分群分析
- 提供租屋推薦結果與市場分析視角
- 結合資料分析與實際 Web 介面呈現
- 操作流程簡單、介面直覺

---

## 👥 租屋族群分類（Personas）

平台目前將租屋市場分為以下幾類：

1. **新婚族／穩定上班族**

   - 坪數適中、屋況較新，兼顧居住品質與生活便利

2. **家庭租屋族**

   - 坪數較大、價格實惠、生活機能與空間需求高

3. **豪宅型租屋族**

   - 高租金、大坪數，重視居住品質與生活體驗

4. **學生／單身上班族**
   - 租金較低、坪數較小，重視地點與交通便利性

## 📊 分群方法說明（Clustering Method）

- 初期嘗試使用「**每坪租金**」作為主要分群特徵

  - Silhouette Score 約為 **3.3**，群間區分度較低

- 後續改以「**總租金金額**」作為主要分析特徵之一
  - Silhouette Score 提升至 **接近 4**
  - 分群結果更符合實際租屋市場與使用者直覺

此調整顯示特徵選擇對分群結果具有顯著影響。
